## 한 장 고르면 끝입니다

SBM4D는 SOOP 방송인 **깡담비**를 위해 만든 하단 배너 이미지 자동 커터입니다.

매번 좌표를 맞춰 자르고, 파일 순서를 확인하고, 이름을 다시 붙이는 과정을 줄이기 위해 만들었습니다. 원본 이미지를 선택하면 SBM4D가 규격을 확인하고, 실제로 잘릴 위치와 순서를 화면에 보여준 뒤, 바로 업로드할 수 있는 PNG 파일로 나눠줍니다.

## SBM4D가 하는 일

| | |
| --- | --- |
| **미리 확인** | 선택한 원본과 분할 위치를 큰 화면으로 보여줍니다. |
| **자동 판별** | 이미지가 지원 규격인지 바로 확인합니다. |
| **순서 표시** | 왼쪽 위부터 오른쪽 아래까지 결과 번호를 표시합니다. |
| **자동 분할** | 좌표를 직접 입력하지 않아도 정확한 크기로 잘라줍니다. |
| **화면 맞춤** | 이미지 비율에 맞춰 프로그램 창 크기를 조절합니다. |
| **바로 반복** | 한 장을 끝내고 다음 이미지를 곧바로 선택할 수 있습니다. |

## 작업 방식이 이렇게 줄어듭니다

| 직접 작업할 때 | SBM4D를 사용할 때 |
| --- | --- |
| 편집 프로그램을 열고 좌표를 맞춥니다. | 원본 이미지를 한 장 고릅니다. |
| 3장 또는 6장을 하나씩 잘라냅니다. | 규격에 맞춰 한 번에 분할합니다. |
| 좌우·상하 순서를 직접 확인합니다. | 화면의 번호로 결과 순서를 미리 보여줍니다. |
| 파일마다 번호를 붙여 저장합니다. | 이름과 번호를 자동으로 붙여 저장합니다. |

저장 위치를 따로 바꾸지 않으면 원본 이미지 옆에 `output` 폴더가 자동으로 만들어집니다.

## 지원하는 원본

| 원본 크기 | 분할 순서 | 만들어지는 파일 |
| --- | --- | ---: |
| `720×450` | 위에서 아래로 | `720×150` PNG 3장 |
| `1440×450` | 각 행의 왼쪽에서 오른쪽, 위에서 아래로 | `720×150` PNG 6장 |

지원 크기와 정확히 일치하는 한 장짜리 이미지만 처리합니다. 움직이는 GIF나 여러 페이지로 구성된 이미지는 사용할 수 없습니다.

## 결과는 이렇게 만들어집니다

`dambi-banner.png`를 선택했다면 다음과 같은 이름으로 저장됩니다.

```text
dambi-banner_1.png
dambi-banner_2.png
dambi-banner_3.png
...
dambi-banner_6.png
```

- 원본 이미지는 수정하거나 덮어쓰지 않습니다.
- 화면의 흰색 분할선과 번호는 결과 이미지에 들어가지 않습니다.
- 같은 이름의 결과가 이미 있으면 덮어쓰기 전에 먼저 확인합니다.
- 원본의 투명 영역이 있다면 결과 PNG에도 유지됩니다.

## 이런 실수를 줄여줍니다

- 배너 높이를 잘못 잘라 다시 작업하는 경우
- 6장 이미지의 좌우 순서를 뒤바꾸는 경우
- 결과 파일 번호를 잘못 붙이는 경우
- 기존 결과를 실수로 덮어쓰는 경우
- 저장한 폴더를 다시 찾아 헤매는 경우

## 만든 이유

SBM4D의 목표는 기능을 많이 넣는 것이 아니라, **이미지 한 장을 고르고 한 번 누르면 끝나는 것**입니다.

복잡한 편집 프로그램을 열지 않고도 깡담비 방송에 필요한 하단 배너를 빠르고 같은 방식으로 준비할 수 있도록, 꼭 필요한 미리보기·분할·저장 과정만 담았습니다.
