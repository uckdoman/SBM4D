# SBM4D

**SOOP BANNER MAKER FOR DAMBI**

[깡담비](https://www.sooplive.com/station/cjstkdbsl3) 방송에서 쓸 하단 배너를 자르려고 만든 작은 프로그램입니다.

배너를 새로 만들 때마다 편집 프로그램을 켜고, 같은 좌표로 자르고, 순서대로 이름을 붙이는 일이 생각보다 귀찮았습니다. 그래서 규격에 맞는 이미지 한 장을 고른 다음 버튼 한 번만 누르면 끝나도록 만들었습니다.

프로그램을 켜서 `이미지 선택`을 누르면 원본이 바로 보입니다. 흰 선과 번호로 어디가 몇 번째 파일이 될지 확인하고 `PNG로 자르기`를 누르면 됩니다. 이미지 모양에 따라 창 크기도 알아서 맞춰집니다.

결과는 원본 이미지 옆 `output` 폴더에 저장됩니다. 다른 곳에 저장하고 싶을 때만 경로를 바꾸면 됩니다. 작업이 끝나면 다음 이미지를 골라서 그대로 반복할 수 있습니다.

## 어떻게 잘리나요?

`720×450` 이미지는 위에서부터 세 장으로 자릅니다.

`1440×450` 이미지는 왼쪽 위부터 오른쪽 아래까지 `1, 2, 3, 4, 5, 6` 순서로 자릅니다.

완성되는 이미지는 모두 `720×150` PNG입니다. 원본 이름이 `dambi-banner.png`라면 `dambi-banner_1.png`부터 차례대로 이름이 붙습니다.

미리보기의 흰 선과 번호는 위치를 확인하기 위한 표시일 뿐, 완성된 이미지에는 들어가지 않습니다. 원본 파일도 건드리지 않습니다.

## 알아둘 점

현재는 `720×450`과 `1440×450` 두 규격만 받습니다. 크기가 다르면 억지로 늘이거나 줄이지 않고, 잘못된 규격이라고 알려줍니다.

움직이는 GIF나 여러 페이지가 들어 있는 이미지는 사용할 수 없습니다. 같은 이름의 결과 파일이 이미 있다면 바로 덮어쓰지 않고 먼저 물어봅니다.

깡담비 방송에 필요한 하단 배너를 빠르게 준비하는 것, SBM4D가 하는 일은 딱 거기까지입니다.
